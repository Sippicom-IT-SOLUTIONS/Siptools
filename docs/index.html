Getting started

Up and running in seconds

No installer, no setup wizard. Open PowerShell and run a single line — or download the binary for offline use.

1

Open PowerShell

Launch Windows PowerShell or Terminal. Run as Administrator for tools that change system state (RootOfTrust, PaperJamZero, TurnKey).

2

Run the one-liner

Paste the hub command — irm … | iex — to open the interactive menu, or use any individual tool's one-liner from the cards above.

3

Pick your tool

Select a tool from the menu and go. Nothing is installed or persisted — the code is fetched and executed straight in memory.

🔒
Internal / proprietary. Siptools is built and maintained by SIPPICOM IT-Solutions for its own and its customers' environments. Review the source on GitHub before running anything with irm … | iex in a production environment.
