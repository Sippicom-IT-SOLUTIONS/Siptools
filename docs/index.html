The SIPPICOM
admin toolkit for Windows.

The tools SIPPICOM uses on customer workstations and servers: signing RDP files, fixing print spoolers, scanning networks, setting up new PCs, generating passwords and diagnosing support tickets. Each tool is one 64-bit .exe that needs no installer. A PowerShell one-liner downloads it to %TEMP% and starts it.

Show the hub command See what each tool does

One line opens the menu

Paste it into Windows PowerShell. The menu lists RootOfTrust, PaperJamZero, TurnKeyPC, TurnKeyFast, CtrlAltPass and PingMeMaybe, plus an option that saves all six .exe files to the current folder. The tool you pick is downloaded to %TEMP% and started from there.

PS> irm https://raw.githubusercontent.com/Sippicom-IT-SOLUTIONS/Siptools/main/main.ps1 | iex

Not in the menu: the Diagnosezentrum. It needs its asset folder, so it ships as a ZIP download.

Scripts blocked? Every tool card links its .exe directly, see Without PowerShell.

The tools

Every tool runs on its own. Copy its one-liner or download the .exe.

Diagnosezentrum ZIP

Diagnostics & repair center, v1.9.4

Support-desk tool with a German Windows interface. Pick checks as tiles, run them at once and get a report for the ticket or the customer. Needs no installation.

Download ZIP ZIP on GitHub

What it checks

  • 8 categories, search and one-click profiles
  • System, network, Microsoft 365, Outlook and printers
  • Repairs that always ask first (SFC, DISM, DNS, spooler, OneAuth)
  • TXT/HTML report compared with the last run

Quick start

  1. Download the ZIP, unblock it (Properties) and extract all files into one folder.
  2. Start Sippicom_Diagnosezentrum.bat. For repairs use Run as administrator.
  3. Pick a profile or tiles and click Diagnose starten.
  4. Find the report in C:\SippicomInstall\diagnose.

RootOfTrust

RDP signing & certificates

Creates a code-signing certificate, trusts it on the machine and signs .rdp files, so Remote Desktop no longer warns about an unknown publisher.

  • 2048-bit RSA / SHA-256 self-signed code-signing certificate
  • Installs it into Trusted Root and Trusted Publisher
  • Signs .rdp files with Windows' own rdpsign.exe
  • Lists created certificates and removes them from the stores again

PaperJamZero

Print spooler repair & printer migration

Restarts the print spooler, clears stuck jobs, brings offline queues back and moves printers from one machine to another.

  • Restarts and checks the Windows Print Spooler
  • Deletes stuck .SPL / .SHD spool files
  • Resets offline queues and adds TCP/IP printers by IP address
  • Printer backup and restore with PrintBrm.exe

CtrlAltPass

Password & PIN generator

Generates passwords, word-based passwords and PINs from a cryptographically secure random source.

  • Random passwords from RNGCryptoServiceProvider
  • Word mode with 238 German words, written without umlauts so any keyboard can type them
  • Custom patterns such as [A-Z]{4}-[0-9]{4}, with a check that the pattern is valid
  • Numeric PINs and one-click copy

PingMeMaybe

Network scanner & topology map

Scans the local subnet, draws what it finds as a network map and traces the route to any device.

  • WAN IP, DNS benchmark, Wi-Fi scan and speed test

Install

There is nothing to install in the usual sense. Pick the path that works on the machine in front of you.

With PowerShell

  1. Open Windows PowerShell or Terminal. Use Run as administrator for RootOfTrust, PaperJamZero and TurnKey, because they change system settings.
  2. Paste the hub command or a tool's own one-liner from its card.
  3. The loader downloads the .exe to %TEMP% and starts it. The file stays there until you delete it.

Without PowerShell

On machines where scripts are blocked, download the .exe and start it directly. The tools are .NET programs and use the .NET Framework that ships with Windows, so nothing else has to be installed.

Open the bin folder on GitHub

Before you run it: Siptools is maintained by SIPPICOM IT-Solutions for its own and its customers' machines. irm … | iex runs whatever the URL returns, so read the loader script on GitHub first. Each loader is a few lines long: it downloads one .exe and starts it.
